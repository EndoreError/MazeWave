# MazeWave 🌀

Генератор лабиринтов с процедурным ландшафтом и поиском оптимального пути.

## О проекте
Программа генерирует идеальный лабиринт с помощью алгоритма поиска в глубину (DFS), после чего накладывает на него процедурный ландшафт (биомы). 
По желанию пользователя в лабиринте можно пробить дополнительные петли (удалить тупики), а затем программа находит оптимальный путь от старта до финиша, учитывая стоимость прохождения через разные типы местности.

## Особенности
- **Генерация лабиринта:** Алгоритм поиска в глубину (DFS). Финиш всегда находится на достаточном удалении от старта.
- **Генерация циклов:** Опциональное удаление тупиков для создания петель и альтернативных маршрутов.
- **Процедурный ландшафт:** Генерация карты высот и влажности на основе шума с последующим сглаживанием (Box Blur) и нормализацией.
- **Поиск пути:** Реализован алгоритм Дейкстры. Путь ищется с учетом весов (стоимости) клеток (например, вода — 10, дорога — 1).
- **Визуализация:** Отрисовка через `matplotlib` с сохранением результата в PNG.
- **Безопасный ввод:** Защита от некорректного ввода данных пользователем.
- **Конфигурация:** Все настройки (цвета, стоимости прохода, размеры, вероятности) вынесены в `src/config.py`.

## Структура проекта
```text
mazewave/
├── README.md
├── requirements.txt
├── main.py              # Точка входа, интерфейс командной строки
├── src/
│   ├── __init__.py
│   ├── config.py        # Настройки параметров (dataclasses)
│   ├── terrain.py       # Типы местности и их свойства
│   ├── cell.py          # Одна клетка (хранит высоту, влажность, террейн)
│   ├── maze.py          # Сетка лабиринта и методы поиска соседей
│   ├── maze_generator.py# DFS-генерация, ландшафт и создание циклов
│   ├── pathfinder.py    # Алгоритм поиска пути Дейкстры
│   └── visualizer.py    # Отрисовка лабиринта, стен и пути
├── tests/               # Unit-тесты (в планах)
└── results/             # Папка для сохранения картинок
```

## Установка и запуск
1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Запустите `main.py`:
   ```bash
   python main.py
   ```
3. Следуйте инструкциям в консоли:
   - Введите размеры (от 3 до 100) и seed. Если seed = 0, сгенерируется случайный.
   - Выберите, генерировать ли ландшафт (введите `0` для генерации).
   - Выберите, создавать ли циклы (введите `0` для генерации петель).
4. Результат сохранится в файл `maze_result.png` и откроется автоматически.
