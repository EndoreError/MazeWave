# MazeWave 🌀

Генератор лабиринтов с процедурным ландшафтом и поиском оптимального пути.

## О проекте
Программа генерирует идеальный лабиринт с помощью алгоритма DFS, после чего накладывает на него процедурный ландшафт (биомы). 
В планах — поиск пути с учетом стоимости разных типов местности.

## Особенности
- **Генерация лабиринта:** Алгоритм поиска в глубину (DFS). Финиш всегда находится на достаточном удалении от старта.
- **Ландшафт:** Генерация на основе шума с последующим сглаживанием (Box Blur) и нормализацией. Поддерживаются биомы: Вода, Песок, Трава, Горы.
- **Визуализация:** Отрисовка через `matplotlib` с сохранением результата в PNG.
- **Конфигурация:** Все настройки (цвета, стоимости прохода, размеры) вынесены в `src/config.py`.
