# MazeWave 🌀

Генератор лабиринтов с процедурным ландшафтом и поиском оптимального пути.

## О проекте
Программа генерирует лабиринт с помощью алгоритма DFS, после чего накладывает на него процедурный ландшафт (биомы). 

## Особенности
- **Генерация лабиринта:** Алгоритм поиска в глубину (DFS). Финиш всегда находится на достаточном удалении от старта.
- **Ландшафт:** Генерация на основе шума с последующим сглаживанием и нормализацией.
- **Визуализация:** Отрисовка через `matplotlib` с сохранением результата в PNG.
- **Конфигурация:** Все настройки (цвета, стоимости прохода, размеры) вынесены в `src/config.py`.
